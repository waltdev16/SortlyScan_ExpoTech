# SortlyScan Vision v1

- Architecture: MobileNetV3-Small, ImageNet transfer learning.
- Dataset: TrashNet (Gary Thung and Mindy Yang, MIT), 2,521 images after cleaning.
- Categories: plastic, paper, cardboard, metal, glass, other waste. Organic waste is not supported.
- Original held-out test: 376 images; reported accuracy 90.7%, macro F1 89.4%.
- With the uncertainty threshold: 91.2% coverage, 95.3% accuracy on accepted images.

These are historical metrics from the original project documentation, not new test results. Classroom performance has not been established.
