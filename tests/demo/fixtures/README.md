# Imágenes de prueba

`plastic_plastic101.jpg` proviene del conjunto de **prueba** de TrashNet (Gary Thung y Mindy Yang,
licencia MIT), el mismo archivo que usan las pruebas de regresión del backend
(`backend/tests/fixtures/vision/` en la rama `development-v2`). Con el modelo `sortlyscan-vision-v1` el
backend lo identifica como plástico (confianza 0,9249). No contiene personas ni datos personales.
